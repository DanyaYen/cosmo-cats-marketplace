# Cosmo Cats Marketplace API

Backend-сервіс маркетплейсу товарів для космічних котів, розроблений у межах курсу **Modern Commerce Development with Java or Kotlin (V3)**.

## Стек технологій
- **Java 21** & **Spring Boot**
- **Spring Web** & **Jakarta Bean Validation**
- **MapStruct** (мапінг між Domain та DTO)
- **Springdoc OpenAPI 3.0** (`/swagger-ui/index.html`)
- **RFC 9457 (`ProblemDetail`)** для стандартизованої обробки помилок

## Запуск проєкту

    ./gradlew bootRun
